# Maymori demo instructions

These instructions apply to everything under `apps/maymori-demo/`.

- Keep all Maymori-specific copy, visual direction, contact details, configuration, scripts, and assets inside this app.
- Treat this site as an independent client concept until a signed client relationship is confirmed.
- Retain the `noindex, nofollow` directive while the site is a speculative or private demo.
- Keep concept-image and unofficial-site disclosures visible and accurate.
- Do not invent services, prices, availability, ratings, testimonials, results, or client approval.
- Use only licensed, public-listing, or client-approved media. Replace temporary imagery before production launch.
- Confirm the official brand spelling with the client before changing existing `Maymorii Studio` copy; the workspace folder uses the requested `maymori-demo` slug.
- Keep WhatsApp and other contact destinations clearly attributable to the client, never to Nexura Labs.
- Do not add dependencies on Nexura-specific branding. Shared imports must come only from `packages/shared-components/` and remain client-neutral.
